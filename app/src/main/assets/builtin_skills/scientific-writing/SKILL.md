# 科研写作与数据分析

科研写作的标准只有一个：**别人能按你写的复现出来。**

## 方法描述要够详细

读者需要知道：

- **用了什么**（设备型号、软件版本、参数）
- **怎么做的**（步骤、顺序、时长）
- **多少样本**（数量、如何选取）
- **对照组是什么**

**版本号不能省** —— 「用 PyTorch 训练」不够，要写「PyTorch 2.1.0」。

## 结果怎么写

**先说结论，再给数据**

```
❌ 表 1 显示了各组数据。A 组平均 23.4，B 组 31.2，C 组 28.9……

✅ B 组效果最好（31.2 ± 2.1），比 A 组高 33%。C 组介于两者之间。
```

**数字要带不确定度**
- 均值 ± 标准差
- 样本量 n
- 显著性（如果做了检验）

**不要隐藏不利结果** —— 挑着报等于造假。

## 数据核对

拿到数据先做这几件事：

1. **看范围** —— 有没有离谱的值（身高 300cm）
2. **看缺失** —— 缺多少、缺在哪些字段
3. **看分布** —— 是否严重偏态（决定用均值还是中位数）
4. **看重复** —— 有没有完全重复的行（可能是采集错误）
5. **看单位** —— 是否统一（秒/毫秒混用是经典错误）

**异常值不要直接删** —— 先查原因，是采集错误才删，是真实极端值要保留并说明。

## 图表

| 数据关系 | 图型 |
|---|---|
| 趋势（随时间） | 折线图 |
| 比较（分类） | 柱状图 |
| 分布 | 直方图 / 箱线图 |
| 相关性（两个连续变量） | 散点图 |
| 占比 | 饼图（类别 ≤5 时） |

**规矩**：
- 必须有坐标轴标签和单位
- 图例要说清每一条是什么
- 误差棒要有说明（是 SD 还是 SEM）
- 不要在 y 轴截断来夸大差异（除非明确标注）

## 可复现性

最低要求：

- 数据在哪（路径/链接）
- 代码怎么跑（命令、依赖版本）
- 随机种子固定
- 环境怎么搭

**如果别人复现不出来，结果就没意义。**

## 写作语言

- 用过去时描述已做的实验（「我们测量了」）
- 用现在时描述普遍事实（「水在 100°C 沸腾」）
- 避免「我们认为」「似乎」这类含糊表达，除非确实不确定
- 数字和单位之间加空格（`5 mL` 而非 `5mL`，中文语境视规范）
