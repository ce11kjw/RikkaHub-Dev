# 界面审查

「说不上哪不对」通常不是审美问题，是**细节不统一**。

## 按这个顺序查

### 一、间距是否成体系

- 所有间距是不是同一套比例？（4/8/12/16/24/32）
- 有没有随手写的 `margin: 13px`？
- 相关的元素是否靠得近、无关的是否离得远？

**最常见的毛病**：哪里都觉得挤，于是每个地方加一点，最后全乱了。

### 二、层级是否清楚

眯起眼睛看，能不能分出：主要信息 / 次要信息 / 操作按钮。

分不出来 → 字号、字重、颜色没有拉开差距。

### 三、对齐

- 左边缘有没有对着同一条线
- 图标和文字是否视觉居中（不是几何居中）
- 数字有没有用等宽（否则会跳动）

### 四、对比度

- 正文 ≥ 4.5:1
- 次要文字 ≥ 3:1
- 禁用态可以低，但要能看出是禁用

### 五、状态完整

三个状态都做了吗：**空状态 / 加载中 / 出错**。

## AI 味的典型症状

界面难看，通常不是因为少了效果，而是因为**每个决策都是默认值**。

- 紫色/蓝色渐变 + 圆角大卡片 + 柔和阴影，三件套
- 所有卡片长得一样，间距一样，没有任何层级
- 每个标题上面加一行全大写小字（EYEBROW）
- 每个链接后面加 `→`
- 一堆图标 + 一句话，凑成三列等宽网格
- 用 emoji 当图标
- 深色模式配霓虹青绿发光边框

这些不是不能用，是**不能默认用**。选了就要能说出为什么。

## 从内容出发，不要从模板出发

动手前问：这个页面是给谁看什么信息的？

- 数据密集的分析页 → 密度优先，留白少，等宽数字，表格感
- 展示型落地页 → 一次一个重点，大量留白
- 工具类操作页 → 效率优先，控件紧凑，快捷键

**同一个"好看的布局"套在这三种上都是错的。**

## 字体和间距

**字体**：
- 正文和标题要真的不同：换字重、换字号跨度
- 一个页面最多两种字体族
- 数字用等宽（`font-variant-numeric: tabular-nums`）
- 行高：正文 1.5-1.7，标题 1.1-1.3

**间距**：用一套比例，**相关的紧，无关的松**。用间距表达关系，比画分隔线干净。

## 颜色

- 一个主色 + 中性色阶，够用了
- 灰至少三档：主文字 / 次要 / 禁用
- 强调色**面积要小** —— 到处都强调等于没有强调

## 动效

- 一次做对一件事：一个精心编排的过渡，好过十个零散动画
- 时长 150-250ms 最舒服，超过 400ms 显得迟钝
- 尊重 `prefers-reduced-motion`
- 不要给静态内容加入场动画

## 交付前自检

- [ ] 缩到手机宽度，有没有溢出、重叠、文字截断
- [ ] 最长的那条数据放进去，布局会不会崩
- [ ] 空 / 加载中 / 出错三态都做了吗
- [ ] 键盘 Tab 走一遍，能不能到所有可交互元素
- [ ] 深色模式下对比度还够吗
- [ ] 字号是否超过 5 种
- [ ] 颜色是否超过 3 个色系

## 怎么给建议

**不要只说"这里不好看"**，要说清三件事：

1. 哪里有问题（具体元素）
2. 为什么会看着不对（原理）
3. 改成什么（给具体值）

例：
> ❌ "卡片间距不太协调"
> ✅ "三张卡片间距 12/16/20px 不一致，改成统一 16px。相关的一组用 8px，组之间用 24px。"

## 不该管的

- 用户明确要的风格（哪怕你不喜欢）
- 品牌色、字体（那是设计规范定的）
- 纯个人偏好
