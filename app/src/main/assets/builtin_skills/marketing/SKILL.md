# 营销与增长

核心只有一句：**说清对谁、解决什么、为什么信你。**

## 文案结构

```
标题：一句话说清价值（不是功能）
副标题：补充关键细节（谁用、什么场景）
正文：3 个具体的好处（不是形容词）
行动：下一步做什么
```

**标题的三种写法**

- 结果导向：`把周报时间从 2 小时压到 10 分钟`
- 痛点导向：`受够了手动对账？`
- 对比导向：`比 Excel 快 20 倍的对账工具`

**不要写的**
- ❌ "业界领先的智能化解决方案"
- ❌ "赋能企业数字化转型"
- ❌ "一站式全链路服务"

这些词谁都能说，等于没说。

## 卖点要具体

| 空话 | 具体 |
|---|---|
| 性能强大 | 10 万条数据 0.3 秒出结果 |
| 安全可靠 | 数据本地加密，不上传服务器 |
| 简单易用 | 三步完成，不用看文档 |
| 兼容性好 | 支持 Windows / Mac / Linux / Android |

**能验证的才是卖点**，不能验证的是形容词。

## SEO 基础

**关键词放在**
- 标题前 30 字
- 第一段
- H2 小标题
- 图片 alt
- URL

**内容结构**
- 一个页面聚焦一个主关键词，不要硬塞
- 长尾词放在小标题和列表里
- 内链指向相关页面（锚文本用关键词，不用"点击这里"）

**别做**
- 关键词堆砌（会被降权）
- 隐藏文字
- 买外链

## 转化路径

```
看到 → 理解 → 相信 → 行动
```

每一环都会流失，所以：

- **看到**：标题要能让人停下
- **理解**：三秒内知道你是干什么的
- **相信**：给证据（案例、数据、客户 logo、试用）
- **行动**：按钮说清做什么（"免费试用" 好过 "提交"）

**减少摩擦**：能一步完成不要两步，能不注册就不注册。

## 落地页检查

- [ ] 三秒内能看懂是干什么的吗
- [ ] 有没有具体数字（不是"很多用户"而是"1.2 万用户"）
- [ ] 有没有降低风险的说明（免费/退款/无需信用卡）
- [ ] 行动按钮是否明显
- [ ] 手机上是否好读

## 别做的事

- 夸大效果（"保证提升 300%"）
- 编造数据或案例
- 用假紧迫感（"仅剩 3 个名额"但永远有）
- 贬低竞品
