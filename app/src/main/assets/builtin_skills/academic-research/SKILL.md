# 学术研究

从「已有的」到「你加的」，中间那一步才是贡献。

## 第一步：文献从哪找

| 领域 | 数据库 |
|---|---|
| 综合 | Google Scholar、Semantic Scholar、Web of Science |
| 计算机 | arXiv、DBLP、ACL Anthology |
| 医学 | PubMed、Cochrane |
| 生物 | bioRxiv、PubMed |
| 物理数学 | arXiv、INSPIRE |

**检索策略**：
1. 先搜近 3 年的综述（review），快速建立地图
2. 再顺着综述的参考文献往回追关键论文
3. 最后用「谁引用了这篇」往前追最新进展

**不要只看高引** —— 高引可能是十年前的，也可能是综述本身。要看方法是否还适用。

## 第二步：读论文的正确顺序

```
标题 → 摘要 → 结论 → 图表 → 方法 → 引言
```

**不要从头读到尾。** 先判断「这篇和我有关系吗」，再决定要不要细读。

读的时候记三个问题：
1. 它解决什么问题
2. 它怎么做（核心思路一句话）
3. 它有什么局限（作者自己说的 + 你看出来的）

## 第三步：组织结构

论文的骨架：

```
1. 问题是什么（为什么重要）
2. 别人怎么做的（有什么不足）
3. 我怎么做（针对哪个不足）
4. 实验证明（比谁好、好多少）
5. 局限（诚实说清）
```

**第 2 步和第 3 步必须有因果** —— 不能是「别人做了 A，我做了 B」，而是「A 在 X 情况下不行，所以我做了 B 来解决 X」。

## 第四步：模拟审稿

写完后自己当审稿人，问这些：

**新颖性**
- 和已有工作比，真正新的是什么？
- 是改进还是新问题？

**方法**
- 假设成立吗？
- 有没有更简单的做法能达到同样效果？

**实验**
- baseline 选得公平吗？
- 指标能否反映真实效果？
- 有没有选择性报告？

**写作**
- 关键贡献能否在摘要里说清？
- 图表能否独立看懂？

**对每个质疑给出回答** —— 回答不了的，就是真问题。

## 引用规范

- **引用要核实** —— 不要把二手转引的文献当原始引用
- **不要堆引用** —— 每个引用都要有作用（支持论点/对比/背景）
- **引用原文要准确** —— 转述和直引区分清楚
- **不要编造** —— 找不到的就说不确定，编一个 DOI 是学术不端

## 诚实原则

- 结果不理想就说清楚，不要只挑好的报告
- 局限要写，藏不住的
- 没做过的实验不要暗示做过
