# 界面设计体系

专业感和业余感的差别，**不在效果多，在体系一致**。

## 配色

**一个主色 + 中性色阶，够了。**

```
主色      #2563EB  按钮、链接、强调
主色浅    #DBEAFE  背景、悬停态
成功      #16A34A
警告      #F59E0B
危险      #DC2626

中性色阶（文字的层级）
文字主    #111827
文字次    #6B7280
文字弱    #9CA3AF
边框      #E5E7EB
背景      #F9FAFB
```

**规则**：
- 主色只用在**要人点的地方**，不要到处涂
- 灰至少三档，全用一个灰等于没有层级
- 深色模式单独定，不要用滤镜反色

## 字体

| 用途 | 字号 | 行高 | 字重 |
|---|---|---|---|
| 页面标题 | 24-32 | 1.2 | 600 |
| 区块标题 | 18-20 | 1.3 | 600 |
| 正文 | 14-16 | 1.6 | 400 |
| 辅助文字 | 12-13 | 1.5 | 400 |
| 数字/表格 | 13-14 | 1.4 | 400 + 等宽 |

**中英混排**：中文用系统字体（苹方/思源），英文数字可用 Inter/系统。字重对齐，不要把英文加粗而中文不加。

## 间距

用一套比例，**不要随手写**：

```
4  8  12  16  24  32  48  64
```

- 元素内部：4-8
- 元素之间：8-12
- 区块之间：24-32
- 页面边距：16-24

**相关的紧，无关的松** —— 用间距表达关系比画线干净。

## 组件规范

**按钮**
- 主要按钮：实心主色，一屏最多一个
- 次要按钮：描边或浅底
- 文字按钮：只用于低优先级操作
- 圆角统一（6/8/12 选一个，全站一致）
- 高度统一（32/36/40 选一个）

**输入框**
- 高度和按钮对齐
- placeholder 用文字弱色，不用正文色
- 错误态：边框变红 + 下方红字说明

**卡片**
- 阴影只用一档，不要深浅混用
- 内边距 16-24
- 卡片之间间距 ≥ 内边距（否则会粘在一起）

## 自检清单

做完对照：

- [ ] 所有间距是否来自同一套数字
- [ ] 字号是否超过 5 种
- [ ] 颜色是否超过 3 个色系
- [ ] 主要操作是否一眼能看到
- [ ] 空/加载/错误三态是否都有
- [ ] 手机宽度下是否溢出
- [ ] 最深和最浅的文字对比度是否够

## 常见错误

- 圆角混用（卡片 12、按钮 4、输入框 8）
- 阴影太重要用"悬浮感"（正确做法是描边 + 极淡阴影）
- 每个区块都加背景色区分（用间距和留白更好）
- 图标风格混用（线条和图填充混着用）
